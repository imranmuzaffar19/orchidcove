# 🏔️ The Orchids Cove — Boutique Luxury Retreat

> **Location:** Brein Nishat, Srinagar, Jammu & Kashmir 190021  
> **Aesthetics:** Kashmiri Craftsmanship meets Modern Minimalist Luxury

**The Orchids Cove** is a dynamic, full-featured web application designed for a luxury boutique resort overlooking Dal Lake and the Zabarwan Mountain range.

---

## ✨ Features

- **💰 Real-Time Multi-Currency Converter**: Switch instantly between **INR (₹)**, **USD ($)**, **EUR (€)**, **GBP (£)**, and **AED (د.إ)** with site-wide live conversion.
- **📅 Dynamic Booking Engine & Rate Calculator**: Live night counter, 18% GST tax calculation, add-on experience selection, discount codes (`WELCOME10`, `KASHMIR15`), and instant printable digital reservation passes saved in `localStorage`.
- **🧳 Reservations Manager & Trip Itinerary Planner**: Slide-out drawers to view active bookings, cancel reservations, or curate a custom Kashmir excursion itinerary.
- **🌙 Light & Dark Luxury Themes**: Seamless toggle between *Light Ivory* and *Dark Midnight Sapphire & Kashmiri Gold* themes.
- **🎵 Web Audio Nature Ambience**: Native browser-synthesized audio of gentle mountain water and Kashmir sitar drone.
- **💬 AI Concierge Chat Assistant**: Interactive floating concierge bubble answering guest queries about weather, Dal Lake, food, and airport transfers.
- **⭐ Guest Reviews & Lightbox Gallery**: Filterable guest feedback, "Write a Review" modal with star picker, and expandable full-screen photo gallery.
- **📱 Fully Responsive & Fast**: Optimized for desktop, tablet, and mobile browsers with zero external framework overhead.

## 🚀 Quick Start & Running Locally

### Option 1: Direct File
Simply open [`index.html`](file:///c:/Users/user/Downloads/orchidcove/index.html) in any modern web browser.

### Option 2: Using NPM / Node.js
Run the following command in the project directory:

```bash
npm start
```

This will launch a local HTTP server at `http://localhost:8080`.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+), Web Audio API
- **Styling**: Vanilla CSS3 with Custom Properties (CSS variables), Glassmorphism, and Flexbox/Grid layouts
- **Fonts**: Fraunces (Serif), Inter (Sans-serif), Space Mono (Monospace) from Google Fonts
- **Storage**: `localStorage` for offline booking & itinerary persistence
